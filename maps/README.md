# Map images

Drop a PNG/JPG per map here. Name it after the map as you'd say it
(`customs.png`, `factory.png`, `reserve.png`, `streets.png`, `labs.png`,
`ground zero.png`) or after tarkov.dev's map `nameId`:

| Map | Accepted file names |
| --- | --- |
| Customs | `customs`, `bigmap` |
| Factory | `factory`, `factory4_day` (night: `factory4_night`) |
| Woods | `woods` |
| Shoreline | `shoreline` |
| Interchange | `interchange` |
| Reserve | `reserve`, `rezervbase` |
| Lighthouse | `lighthouse` |
| Streets of Tarkov | `streets`, `streets of tarkov`, `tarkovstreets` |
| Ground Zero | `ground zero`, `sandbox` (21+: `sandbox_high`) |
| The Lab | `labs`, `the lab`, `laboratory` |
| Terminal | `terminal` |
| The Labyrinth | `labyrinth` |
| Icebreaker | `icebreaker` |

Case, spaces and punctuation don't matter. The quest panel's **Map** button
appears only when an image exists for the map it's showing; the `[` key opens
the map window either way.
